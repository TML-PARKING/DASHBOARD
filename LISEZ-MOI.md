# Dashboard Ops

2 fichiers : `index.html` (l'app) et `auth.html` (la page de retour de la connexion Microsoft).

## 1. Mettre l'app en ligne (une fois, 5 min)
Microsoft n'accepte pas la connexion depuis un fichier ouvert sur le PC : l'app doit avoir une adresse web.

1. Sur github.com : **New repository** → nom `dashboard-ops` → **Public** → *Create repository*.
2. *uploading an existing file* → glisser `index.html` et `auth.html` → *Commit changes*.
3. *Settings › Pages* → Branch : `main` → *Save*. Une minute plus tard, ton app est à :
   `https://TON-PSEUDO.github.io/dashboard-ops/` → mets-la en favori.

## 2. Première connexion (une fois, 3 min)
Ouvre l'app → **Se connecter avec Microsoft** → l'app t'affiche les 5 étapes à suivre, avec les adresses à copier.

## 3. Ensuite, à chaque fois
Ouvre l'app → tu es déjà connecté → **Ajouter des infos** → *Mes mails* ou *Un fichier Excel* → choisis → c'est affiché,
et ça se met à jour tout seul. Le crayon sur chaque bloc permet de choisir les colonnes, les filtres et la forme.

Si la connexion échoue, l'app affiche la cause et quoi faire. Si le message dit
« Ton entreprise demande l'accord d'un administrateur », seul l'IT de TML peut débloquer.
